# go-corporate-communications

기업 커뮤니케이션(홍보·언론 관계·IR과 공시·대관·위기 커뮤니케이션)을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 한국 법·제도(자본시장법 공시, 거래소 공시규정, 언론중재법, 청탁금지법 등)를 뼈대로 미국·EU 기준을 비교합니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식, 조사 자료, 이미지를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

> 튜터의 법규·공시 설명은 학습용입니다. 법률 자문이 아니므로 실제 공시·대응 전에는 공시 담당·법무 확인을 받으세요.

> **공개 전 실적·거래·사고 같은 미공개 정보는 대화에 넣지 마세요.** 연습은 가상 회사나 이미 공시된 사례로 합니다. 튜터는 그런 내용을 기록 파일에 쓰지 않고 웹 검색어에도 넣지 않지만, 대화 자체는 Claude Code 세션 기록에 남고 이 리포가 그 기록을 지울 수는 없습니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-corporate-communications
```

**Claude Code**

```bash
cd ~/Desktop/go-corporate-communications
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-corporate-communications` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 무슨 일을 맡고 있는지, 홍보·IR·대관 경험은 어떤지 짧게 묻고, 영역마다 상황 문제를 하나씩 풀어 출발점을 찾습니다. 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 업무 장면(가상 회사로 바꾼 것)으로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다. 공시·언론·대관 규정이 걸리는 장면에서는 튜터가 국가법령정보센터·거래소 같은 공식 출처를 그 자리에서 확인하고 출처와 조회일을 남깁니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.
6. 마지막에는 실제 업무에 쓸 위기 대응 메시지 맵과 IR 자료 골격을 만듭니다.

이미 나간 보도자료·기사·공시·사과문을 가져오면 그걸로 연습합니다. 기자·투자자의 이름과 연락처는 지우고 가져오세요.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도(S 전략·평판·사내 · M 언론 관계 · I IR과 공시 · P 대관 · K 위기 커뮤니케이션 · X 졸업) |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 업무 문서 초안. 처음 시작할 때 생깁니다 |
| [docs/build/](docs/build/) | 이 리포를 만든 기록과 법령 출처(학습에는 필요 없음) |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

광고·브랜드 마케팅, 위기관리 체계(BCP), ESG 공시, 회사법·준법, 회계 수치처럼 다른 영역은 go-marketing, go-resilience, go-esg, go-compliance-and-legal, go-accounting 같은 별도 워크스페이스가 다룹니다. 여기서는 연결만 짚습니다.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/projects`의 문서 초안을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 민감한 정보는 대화에 넣지 마세요.
